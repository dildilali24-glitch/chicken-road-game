# 🐔 Chicken Road Game

একটি সহজ Chicken Road গেম - মুরগি রাস্তা পার করে

## 🎮 গেম খেলুন

**[এখানে ক্লিক করে গেম খেলুন!](https://dildilali24-glitch.github.io/chicken-road-game)** ⭐

## 🎯 গেমের নিয়ম

- **উদ্দেশ্য:** মুরগিকে রাস্তা পার করে সবুজ এলাকায় পৌঁছাতে হবে
- **বাধা:** লাল গাড়ি এড়িয়ে চলুন
- **কঠিনতা:** প্রতিটি লেভেলে গাড়ির গতি বাড়ে

## 🎮 কন্ট্রোল

### কম্পিউটারে:
- **↑ Arrow Up** - উপরের দিকে যান
- **উপরে ক্লিক করুন** - মাউস দিয়ে খেলুন

### মোবাইলে:
- **উপরের দিকে ঝাঁকুনি দিন** - ত্বরণ সেন্সর দিয়ে খেলুন
- **উপরে ট্যাপ করুন** - স্পর্শ দিয়ে খেলুন
